# 作業報告の実費記録

作業報告の登録フォームで、項目名と金額（円、整数）を最大50件入力できます。実費がない報告は従来どおり登録できます。報告と実費は同じDBトランザクションで保存し、写真登録に失敗した場合の報告取り消しでは未請求実費も取り消します。

管理者の「実費管理」で物件番号・作業日・項目・金額を一覧表示し、未請求明細の項目・金額を修正できます。作業者は実費を登録・閲覧できますが、登録後の金額修正は管理者だけです。顧客は実費の元データを閲覧できません。

今回は実費の記録・修正までです。定額料金の設定、請求情報の作成、顧客のコミュニケーション画面への請求カード表示は次の実装になります。税区分、税額計算、請求締め日もまだ扱いません。

`report_expenses.billed_at`は将来の請求情報作成時にサーバー側で設定する列です。一般クライアントには変更権限を与えません。一度設定した明細は更新・削除（報告削除からの連鎖削除も含む）をDBトリガーで拒否します。請求作成処理は対象明細を行ロックし、項目・金額のスナップショットと請求への紐付けを保存してから、この列を設定する単一トランザクションとして実装します。

公開順序：`20261018230614_report_expenses.sql`を適用し、テーブルのRLSと登録RPCを確認した後、フロントエンドを公開します。既存の報告・写真のレコードは変更しません。
