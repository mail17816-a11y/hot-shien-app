# 作業報告の実費記録

作業報告の登録フォームで、項目名と金額（円、整数）を最大50件入力できます。実費がない報告は従来どおり登録できます。報告と実費は同じDBトランザクションで保存し、写真登録に失敗した場合の報告取り消しでは未請求実費も取り消します。

管理者の「実費管理」で物件番号・作業日・項目・金額を一覧表示し、未請求明細の項目・金額を修正できます。作業者は実費を登録・閲覧できますが、登録後の金額修正は管理者だけです。顧客は自分の物件の作業報告に紐づく実費だけ閲覧できます。コミュニケーション画面の作業報告に項目名・金額・実費合計を付記し、請求公開前の実費も目安として表示します。修正・登録権限は付与しません。

請求情報の作成・公開・撤回は `docs/customer-contract-billing.md` を参照してください。作業報告の実費は現在の記録であり、公開済み請求の金額スナップショットとは別です。税区分、税額計算、請求締め日は扱いません。

`report_expenses.billed_at`は将来の請求情報作成時にサーバー側で設定する列です。一般クライアントには変更権限を与えません。一度設定した明細は更新・削除（報告削除からの連鎖削除も含む）をDBトリガーで拒否します。請求作成処理は対象明細を行ロックし、項目・金額のスナップショットと請求への紐付けを保存してから、この列を設定する単一トランザクションとして実装します。

公開順序：`20261018230614_report_expenses.sql`を適用し、テーブルのRLSと登録RPCを確認した後、フロントエンドを公開します。既存の報告・写真のレコードは変更しません。

実費・請求情報の表示には「請求情報は目安であり、金額は変動する場合があります」を小さな薄い文字で併記します。

顧客向け実費表示の公開時は `20261020100826_customer_report_expenses.sql` を先に適用し、その後フロントエンドを公開します。他顧客・作業者・管理者の権限は既存どおりで、請求下書きの非公開も維持します。
